# 「轻卡」今日记录与食物库增强 —— 设计文档

- 日期：2026-08-21
- 状态：待评审
- 项目仓库：`lightcal`
- 依赖：基于《2026-08-20-diet-tracker-design.md》（v1 已实现并上线自用）

## 1. 概述

v1 自用反馈的四项增强 + 一项补充，全部为现有流程上的有界改动：

1. 饮水记录列入「今日记录」时间线（与食物按时间混排）
2. 「今日记录」支持删除（左滑删除，避免加错）
3. 预设食物列表细化：肉类按部位拆分（不同部位脂肪/热量差异大），面包类补全麦面包
4. 食物图标进一步完善：修复误分类、扩大覆盖

本次改动不引入新数据表、不改变数据模型结构（仅新增 `deleteWaterItem` 数据操作）、不改变录入管线。

## 2. 需求明细

### 2.1 饮水记录列入今日记录

- 现状：`WaterLogItem` 每次「+250ml / +500ml」已落库一条，但「今日记录」卡片只渲染 `FoodLogItem`，饮水仅在饮水卡汇总。
- 目标：饮水与食物统一进入「今日记录」时间线，按 `createdAt` 升序混排；每条饮水单独一行（用户已确认）。
- 饮水行展示：蓝色「饮水」胶囊标签 + `drop.fill` 图标 + 文本「250 ml · 14:30」（容量 + HH:mm 时间）；不显示 kcal。
- 食物行补显示录入时间「HH:mm」（原食物行无时间；混排后时间让顺序可读）。**保持**「鸡胸肉 100g」「133 kcal」等既有文本形态不变（UI 测试依赖）。
- 空状态：「今日记录」在食物与饮水均为空时显示占位文案（现状文案不变）。
- 饮水行不计入热量与营养汇总（水无热量，与 v1 spec 2.3/5.3 一致）。

### 2.2 今日记录删除

- 交互：**左滑删除**（用户已确认）。今日页整体由 `ScrollView` + 卡片改为 `List(.insetGrouped)` 布局——`swipeActions` 只存在于 List 行上，这是视觉代价（卡片内边距/圆角略有变化，卡片内组件不变）。
- 每行 `.swipeActions(edge: .trailing, allowsFullSwipe: true)` 出红色破坏性「删除」按钮（`role: .destructive`，图标 trash），点按即删，无二次确认弹窗（平台惯例：左滑本身就是明确意图）。
- 食物行删除走已有 `DataStore.deleteLogItem`；饮水行删除走新增 `DataStore.deleteWaterItem`。
- 删除后立即 `refresh()`，重算当日汇总、热量缺口、缺口建议（统一走现有刷新路径，避免状态不一致）。
- 范围：仅「今日」页可删。趋势页只读、历史日期记录删除均不在本次范围。

### 2.3 预设食物细化（foods.json 内置库）

### 2.4 食物图标完善

#### 2.4.1 现状问题（全库审计结论）

- 误分类 5 处：鸡蛋、牛奶、牛油果、牛油果酱、牛角包 全部误判为肉图标（fork.knife）——因为「牛/鸡」关键词排在「奶/蛋/果/包」之前且先命中先返回。
- 52 个库内食物名兜底成肉图标（吐司、法棍、蛤蜊、生蚝、辣椒、洋葱、椰子、石榴、卡布奇诺……）。

#### 2.4.2 方案

保持「先命中先返回」的简单结构，重排关键词组顺序（先具体后通用），并做三类修改：

1. **补具体词**：甜品/烘焙/海鲜/蔬果/饮品等词（见下表），把非肉兜底从 52 个降到 1 个（全库仅剩「酱料」）。
2. **删裸关键词**：删除会误伤的裸「甜」「水」「卷」「排」（改为具体词）。例：去掉「卷」后新条目「肥牛卷」由「牛」归肉组而非主食组；去掉「水」后「水果」归水果组而非饮品组。
3. **保留安全裸词**：「饭」「麦」「茄」「海鲜」等单字词保留/回归（炒饭、麦片、番茄、海鲜类依赖它们归类）。
4. **特殊名兜底**：库内唯一「水」精确名直接映射 `drop.fill`；饮水时间线行固定 `drop.fill`。

## 3. 组件与数据流

### 3.1 数据层（DataStore）

- 新增 `deleteWaterItem(_ item: WaterLogItem)`：主上下文删除 + 保存，与 `deleteLogItem` 对称。
- `waterItems(on:)` 补 `SortDescriptor(\.createdAt)` 升序（合并排序确定性）。

### 3.2 视图模型（TodayViewModel）

- 新增 `private(set) var timeline: [TimelineEntry]`，`refresh()` 时组装：
  - `TimelineEntry` 为 enum：`.food(FoodLogItem)` / `.water(WaterLogItem)`，`Identifiable`（用 `persistentModelID`），暴露 `createdAt`、显示名、份量文本、营养快照、餐次标签。
  - 组装：`foods + waters` 后按 `createdAt` 升序稳定排序。
- 新增 `func delete(entry: TimelineEntry)`：分发到 `deleteLogItem` / `deleteWaterItem`，随后 `await refresh()`。

### 3.3 视图（TodayDashboardView）

- 页面结构改为 `NavigationStack { List { Section{…}… } }`，`.listStyle(.insetGrouped)`，`.scrollContentBackground(.hidden)`，背景 `DesignTokens.background`；五个卡片内容原样迁入 Section，去掉卡片自带的 `secondarySystemGroupedBackground` + 圆角（与 List 行背景重复）。
- 工具栏「+」、饮水快加按钮、确认卡片 sheet 逻辑全部不变（accessibilityIdentifier 不变，UI 测试兼容）。
- 时间线行：`ForEach(viewModel.timeline)`；食物行 = 餐次胶囊 + 食物图标 + 「名称 克重」+ HH:mm + kcal（AI 估算三角标不变）；饮水行 = 「饮水」胶囊（蓝色调）+ `drop.fill` + 「250 ml · HH:mm」；行尾 `.swipeActions` 删除。
- `Formatting` 新增 `timeText(_ date: Date) -> String`（HH:mm，用户当前时区）。

### 3.4 图标（FoodIcon）

- 仅替换 `symbolByKeyword` 表为 2.4.3 的表 + 「水」精确名特判；`symbol(for:)` 接口不变。

## 4. 错误处理

- 删除操作沿用现有 `try?` 静默失败风格：删除失败时记录仍在，下一次 `refresh()` 自然恢复展示（无半删除状态）。
- 图标无命中兜底 `fork.knife`（现状行为不变）。
